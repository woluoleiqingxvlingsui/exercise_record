# 装机验收清单

## 一、安装与冷启动

- [ ] 点 `_out\apk\exercise-record-0.7.0-debug.apk` 能装上（首次需允许「未知来源」）
- [ ] 桌面出现「训练记录」图标，点开不闪退
- [ ] ⚠ 首次启动会弹**通知权限**（Android 13+）——点「允许」，第三节要用
- [ ] 顶部标题、底部四个 Tab（计划/训练/日历/统计）都在，不被状态栏或手势条遮挡
- [ ] **首次进入「计划」页能看到 5 个内置示例**（引体日 / 推日 / 日常有氧跑 / 强度跑 / 长距离跑）
- [ ] 切到后台再切回来，界面不空白、不需要刷新

## 二、计划编辑

- [ ] 点「新建计划」→ 填名字、**自己输一个类别**（比如「腿」）→ 加一个动作 → 保存成功
- [ ] ⚠ 类别是**自由输入**的：填过的类别会变成可点的标签，下次直接点就能复用
- [ ] ⚠ **长按**某个类别标签 → 弹出确认框 → 点「删除」后该标签消失；已有的计划照旧能用（只是不能再一键选中）
- [ ] 打开「引体日 → 编辑」，能看到 热身 / 正式组 / 放松 三个阶段与 10 组
- [ ] ⚠ **每个动作只有一个「组间歇」**（不再有"最后一组后 / 换动作过渡 / 阶段过渡"那几层）
- [ ] ⚠ **组间歇按「秒」填**（例如 90），保存后再打开**显示仍是 90**（单位没有被 ×1000 或 ÷1000 搞错）
- [ ] 「展开逐组编辑」后能给某一组单独设不同的次数/重量（间歇仍是该动作那个统一值）
- [ ] ⚠ 点**「查看」**：只读地展示计划的全部安排（阶段 / 动作 / 每组目标 / 组间歇）
- [ ] ⚠ 只读查看里**没有任何可以改动的地方**，只有「关闭」；随便点一圈之后计划内容不变
- [ ] 删除一个计划，已完成的历史记录不受影响

## 三、⚠ 组间歇通知栏倒计时（本项目的核心）

先选「引体日」开始训练，走完热身第 1 组。

- [ ] 点「完成本组」→ 弹出询问，且有 **「按计划推进 · 休息 X」** 与 **「灵活调整」** 两个按钮
- [ ] ⚠ 浮层上的「已等待」秒数**在走**（说明询问期的计时刷新正常）
- [ ] 点「按计划推进」→ 进入组间歇倒计时，页面中央是大数字 + 进度环
- [ ] ⚠ **下拉通知栏能看到倒计时卡片，且数字在往下走**（不是往上走）—— **这一条是必过的**
- [ ] ⚠ **锁屏 1 分钟再解锁**，倒计时数字与真实时间一致（走字由系统绘制）
- [ ] ⚠ **息屏 / 切后台 ≥5 分钟**，回来倒计时仍然准确
- [ ] ⚠ 倒计时归零时**震动明显变长**（连震 5 下、约 3 秒），不再是"只震一下"
- [ ] ⚠ 全程**不应该**再出现独立的「休息结束」通知（已按需求去掉，避免与常驻卡重复）
- [ ] ⚠ 点常驻通知 → **直接回到训练页**（而不是回到你上次待着的那个页面）
- [ ] 若训练还在进行，点通知后应**直接接着练**，不用再点一次「继续」
- [ ] 结束后（训练完成或退出）常驻通知消失

### 三之二、⚠ 灵活调整（需求重点）

- [ ] 点「灵活调整」后，顶部**醒目显示「原计划间歇 X」**
- [ ] 快捷档位里**「计划」那一档是高亮**的
- [ ] 选 120 秒 → 「本组休息」变成 2:00，并显示**「比计划 +30 秒」**
- [ ] 点「开始休息」→ 倒计时**按 120 秒**走（不是按原计划）
- [ ] 练完后在「统计 → 这条记录」里能看到：**计划 X 秒 / 实际 120 秒**，且标记为「调整」
- [ ] 「更多调整」里的 加组 / 减组 / 跳过下一组 / 结束本动作 都能生效

### 三之三、⚠ 询问超时兜底

- [ ] 在设置里把兜底设成 10 秒
- [ ] 完成一组后**直接锁屏**等 15 秒以上，再回 App
- [ ] App 应提示「询问超时，已按计划推进」，且**倒计时是按计划在走**（而不是根本没计时）
- [ ] 这条记录里标注为「自动」

### 三之四、结束训练的两个选择

在训练页点左上角「退出」。

- [ ] 弹层里有**三个**按钮：**结束并保存** / **结束，并不保存** / 继续训练
- [ ] 点「结束，并不保存」→ **会再弹一次二次确认**（防误触）→ 点「丢弃并结束」
- [ ] 丢弃后：记录列表里**找不到**这次训练，日历上**也没有**这一天
- [ ] 再练一次，这次点「结束并保存」→ 记录里能看到它，日历上也有圆点

## 四、⚠ 杀进程恢复与启动提示

- [ ] 开始训练 → 做完 2 组 → 切后台 → 从最近任务里**上划杀掉 App**
- [ ] ⚠ **重新打开 App，立刻（不用自己切 Tab）就弹出「上次训练还没结束」**，并显示计划名、日期、已完成 X/Y 组
- [ ] 点「继续这次训练」→ 直接进入训练页，已完成的组数与进度都对，能接着做下一组
- [ ] 再杀一次，这次在弹层里点「结束并保存」→ 记录里出现这次训练、日历上有圆点
- [ ] 再杀一次，这次点「结束，并不保存」→ 二次确认后，记录与日历里都没有它
- [ ] 杀掉 App 10 分钟后再开，进度仍在

## 五、训练后反馈

- [ ] 练完（或退出）后弹出训练详情
- [ ] ⚠ 详情里第一项是**「训练时长（分钟）」**，已按 App 计时结果预填；把它改成实际练的时间再保存
- [ ] 拖动 RPE 滑块，数字跟着变
- [ ] 点选体感、不适部位，填备注与「下次想调整什么」，点「保存」
- [ ] 回到「统计」页，这条记录显示 **「已记感受」**
- [ ] 重新打开这条记录，填过的内容都还在，**时长也还是改过的那个值**

## 六、训练日程（底部第三个 Tab，叫「日程」）

- [ ] 练完一次后，**日历上对应那天自动出现圆点**（统一一个颜色，不再区分力量/有氧色）
- [ ] ⚠ 折叠时每格只有日期 + 一个圆点；**手指在日历上向下滑**，每格下面展开列出当天练了什么；**向上滑**收起
- [ ] ⚠ **没有展开/收起按钮**，只能靠手势；日历里也不该有任何手势说明文字
- [ ] ⚠ **跟手**：按住往下拖时每格高度要**跟着手指一点点变高**（不是拖到一半突然跳变），松手才吸附到位
- [ ] ⚠ **快速轻扫**一下（不用拖过半程）也应该能展开/收起
- [ ] ⚠ **滑动手感**：展开后页面变长时，在日历上**上滑应该只收起日历、不带动页面滚动**，全程不卡顿
      （在日历以外的区域滑动，页面正常滚动）
- [ ] ⚠ 展开状态在**切 Tab 再回来时保持**，不用每次重新滑
- [ ] 只排了计划没练的那天，圆点是**空心**的
- [ ] ⚠ 这一页**只放日程**，不应再出现「本月 X 次 · X 分钟」这类统计（统计统一在「统计」页）
- [ ] 点那一天 → 下方详情显示这次训练、组数、时长
- [ ] 点「安排计划」能给任意一天加计划条目（日历上出现空心圆点，展开后能看到计划名）
- [ ] ⚠ 详情下方三个操作**「记录训练 / 安排计划 / 休息日」排在同一行**，三个都带图标
- [ ] 点「休息日」→ 该天出现"休"角标；再点可取消
- [ ] 删除计划条目有反应（安排错了可以直接删掉那个条目）
- [ ] ⚠ 上个月/下个月切换正常，1 号与星期的对齐正确

## 六之一、⚠ 记录训练（当天练了但没走 App）

- [ ] 选中某天 → 点 **「记录训练」** → 弹层里有两种记法：**按计划记录 / 简单记一笔**
- [ ] **按计划记录**：选一个计划 → 填分钟 → 保存；当天出现圆点，详情里这条标着「记录」
- [ ] **简单记一笔**：只填**训练类别 + 分钟**（例如「有氧 / 30」）→ 保存，一样进日历和统计
- [ ] ⚠ **不需要**把计划里的组挨个点一遍「完成/跳过」就能记上这次训练
- [ ] 自己新写的类别（比如「有氧」）下次在记录弹层里能直接点选
- [ ] 记录完 → 切到「统计」页，这条已计入总时长与「按类别」，列表里带「记录」标记
- [ ] 这类记录点进去能看到时长、能改，也能删除

## 六之二、统计（底部第四个 Tab）

- [ ] 顶部有三个粒度按钮：**按周 / 按月 / 按年**
- [ ] ⚠ 大数字是**该周期的训练总时长**；下面同时给出**训练次数**和**平均每次**
- [ ] ⚠ 总时长、分类时长、柱状图**都按「你记录的训练时长」算**，不是 App 秒表的流逝时间
      （可验证：把某条记录的时长改大/改小，统计里的总时长跟着变）
- [ ] ⚠ 有**「按类别」**分项：每个训练类别各占多少时长、各几次（你自己新建的类别也要能出现）
- [ ] 用 ‹ › 能**翻到上一个 / 下一个**周、月、年
- [ ] ⚠ 翻到没有训练的周期时，显示「这个周期没有训练记录」，而不是空白或报错
- [ ] 柱状图：按年是 12 个月、按周是 7 天、按月是当月天数
- [ ] 点某条记录能进详情、补记感受

## 七、数据持久化与备份

- [ ] 杀进程重开、关机重开后，计划与记录都还在
- [ ] 设置 → 导出为文本 → 复制，能拿到 JSON（可粘到备忘录验证）
- [ ] ⚠ **导入往返**：在另一台手机（或清空数据后）把 JSON 粘回去导入，计划/记录/日程都能恢复
- [ ] 导入时选「合并」，已有的记录不会被覆盖
- [ ] 卸载 App 后数据清空（预期行为）

## 八、⚠ 小米 / HyperOS 专项（通知栏或锁屏看不到卡片时按顺序查）

- [ ] ① 先启动计时再锁屏（有些 ROM 只在计时开始后放行锁屏通知）
- [ ] ② 设置 → 通知与控制中心 → 锁屏通知 → **显示所有通知内容**
- [ ] ③ 设置 → 应用 → 训练记录 → 通知 →「**训练计时**」渠道 → 锁屏 = 显示所有内容
- [ ] ④ 权限管理里「**锁屏显示**」= 允许
- [ ] ⑤ 省电策略 = **无限制**；「**自启动**」= 允许（否则切后台久了服务可能被清）
- [ ] 通知栏下拉能看到、只有锁屏看不到时，基本就是上面几处之一没开，**不是 App 的 bug**

## 九、有氧模式

- [ ] 选「日常有氧跑」开始训练：热身段 / 主课段是**连续段**，只走正计时，**不弹「按计划推进/灵活调整」**
- [ ] 连续段之间的过渡间歇仍会倒计时
- [ ] 选「强度跑（1000m 间歇）」：4 组 1000m 之间**会弹询问并有组间歇**

---

## 已知限制（不是 bug）

- 通知栏卡片是否在**锁屏**可见由厂商 ROM 决定，见第八节
- **数据只在手机上**，卸载即清空；备份只能靠设置里的导出/导入
- 有氧不采集 GPS 轨迹，距离/配速靠手填
- 只有浅色主题
- release 与 debug 签名不同，不能互相覆盖安装
